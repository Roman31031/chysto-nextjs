# чисто. — Next.js проєкт

Перенесено з чат-прототипу (`chysto-prototype.jsx`) у структуру Next.js для реального деплою.

## Структура

- `app/page.js` — головна сторінка
- `app/posluhy/[slug]/page.js` — усі 6 сторінок послуг (один файл, дані з `lib/data.js`)
- `app/blog/[slug]/page.js` — усі 19 статей блогу (один файл)
- `app/layout.js` — спільна шапка/футер, Schema.org розмітка
- `components/Shared.jsx` — усі UI-компоненти (калькулятор, чек-листи, форми тощо)
- `lib/data.js` — послуги, статті, FAQ, кольори бренду
- `lib/routes.js` — карта URL-адрес і мета-теги (title/description) для кожної сторінки

## Що далі

1. Завантажити цю структуру на GitHub
2. Підключити до Vercel (автоматично розпізнає Next.js)
3. Прив'язати домен chysto.mk.ua у налаштуваннях Vercel

Детальний покроковий план — у файлі `План-деплою-сайту.md` в чаті.
